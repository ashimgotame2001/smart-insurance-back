# Skill File Template

Use this template when adding new focused skill files under `java-agent/`.

```markdown
# {Skill Title}

## Purpose

One paragraph: what this skill helps the agent do.

## When to Use

- Bullet triggers for loading this file

## Rules / Workflow

Numbered steps or bullet rules.

## Output

What the agent should produce when applying this skill.

## Related

- [link-to-related-skill.md](../path/to-skill.md)
```

## Guidelines

- Keep under ~80 lines
- One concern per file
- Link to related skills instead of duplicating content
- Use tables and checklists for scanability
