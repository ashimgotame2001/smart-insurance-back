# API Review Checklist

- [ ] OpenAPI spec matches implementation
- [ ] Paths follow kebab-case plural convention
- [ ] operationId unique and stable
- [ ] Request/response schemas complete
- [ ] Required fields marked
- [ ] List endpoints paginated
- [ ] Sort/filter params documented
- [ ] HTTP status codes correct
- [ ] Error responses documented
- [ ] Security requirements declared
- [ ] Requirement ID in description or extension

See [../openapi/openapi-contract-review-skill.md](../openapi/openapi-contract-review-skill.md).
