# Performance Review

## Check

- [ ] List endpoints paginated with sane defaults
- [ ] DB queries use indexes for filters
- [ ] List APIs use JPA projections for summary fields
- [ ] No N+1 query patterns
- [ ] External calls have timeouts
- [ ] Heavy processing async where appropriate
- [ ] No unbounded in-memory collections from DB

See [../programming/performance-skill.md](../programming/performance-skill.md).
