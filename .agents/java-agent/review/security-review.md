# Security Review

## Check

- [ ] Endpoints authenticated and authorized
- [ ] Resource ownership validated
- [ ] Input validation on all write operations
- [ ] No secrets in code or logs
- [ ] PII redacted in logs
- [ ] SQL injection prevented (parameterized queries)
