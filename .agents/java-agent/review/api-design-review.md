# API Design Review

## Check

- [ ] OpenAPI spec exists and matches implementation
- [ ] REST paths follow standard ([../openapi/api-path-standard-skill.md](../openapi/api-path-standard-skill.md))
- [ ] Request/response schemas complete
- [ ] HTTP status codes correct
- [ ] List APIs paginated
- [ ] operationId stable and traceable
- [ ] Error responses documented

Run [../checklists/api-review-checklist.md](../checklists/api-review-checklist.md).
